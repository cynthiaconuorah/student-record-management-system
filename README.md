# Student Record Management System

## Overview

A Python-based student record management application developed as a course project for Advanced Application Development (IT 3883). The application allows users to create, view, modify, save, and process student records through a menu-driven interface.

## Technologies

- Python
- Dictionaries
- Functions
- Conditional Logic
- Exception Handling
- File I/O
- OS Module

## Features

- Add student records
- Display student information
- Validate GPA input
- Remove GPA information from a record
- Save student records to a text file
- Load saved records and categorize students
- Automatically classify students based on GPA

## GPA Classification

| GPA | Classification |
|---|---|
| 3.5 or higher | Dean's List |
| 2.0–3.49 | Regular Standing |
| Below 2.0 | Academic Probation |

## What I Learned

This project provided hands-on experience with Python data structures, functions, user input validation, exception handling, file-based data persistence, and implementing business logic to process and categorize records.
